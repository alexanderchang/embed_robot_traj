# 四、常见故障排查（汇川伺服专属）

## 1. EtherCAT 链路故障

* **现象** ：主站初始化失败、无法进入 OP 状态
* 排查：
  1. 网线使用 **CAT5e 屏蔽线** ，总线末端伺服拨码打开 **终端电阻** ；
  2. 伺服 `H00-02`确认设为 `2(EtherCAT)`；
  3. 关闭 Linux 网卡节能：`sudo ethtool -C eth0 rx-usecs 1000`。

## 2. 伺服使能失败（状态字无 0x27）

* **现象** ：控制字下发后伺服不励磁、面板报 `Er.b0.00`（位置偏差过大）
* 排查：
  1. 控制字时序严格按 `0→6→7→F` 执行；
  2. 确认伺服模式为 `8(CSP)`，禁用内部点位；
  3. 断电重启伺服，清除历史故障。

## 3. 电机转动方向反向

* 解决：修改汇川参数 `H04-01`（电机转向），或代码取反脉冲值。

## 4. 定位精度偏差大

* 排查电子齿轮比：`H05-02=10000`、`H05-07/05-09`匹配编码器分辨率；
* 检查机械减速比、丝杠导程是否换算正确。

## 5. 轨迹抖动

* 解决：安装 Linux **实时内核** ，关闭后台占用 CPU 进程；增大 S 曲线加减速参数。

# 五、扩展说明

1. **PDO 扩展** ：如需增加速度、转矩反馈，可在伺服中扩展 PDO 映射，同步修改 `AXIS_RX_LEN/AXIS_TX_LEN`；
2. **多轴同步** ：代码已依托汇川 DC 分布式时钟实现 1ms 硬同步，适合机械臂多轴联动；
3. **单位切换** ：若需改用 `mm/°`为单位，仅修改 `RAD_TO_PULSE`换算系数即可；
4. **固件适配** ：兼容汇川 SV630N/SV660N/IS620N 全系列 EtherCAT 伺服。



# 汇川 EtherCAT 伺服（SV630N/SV660N/IS620N）**一键参数配置清单**

适配本文 `C+++SOEM+Boost` 工程、 **CiA402 CSP 循环同步位置模式** 、1ms EtherCAT 周期、10000 脉冲 / 圈标准单位，分 **快速面板配置** 、 **上位机 InoTouch 批量配置** 、**故障参数修正**三部分，现场直接对照设置即可。

> 前置说明：
>
> 1. 操作方式：伺服面板按键 / 汇川 InoTouch PC 调试软件；
> 2. 总线拓扑：EtherCAT 手拉手串联， **最后一台伺服拨码打开终端电阻** ；
> 3. 统一周期：所有伺服 EtherCAT 周期固定 `1000μs(1ms)`，和代码硬实时周期对齐；
> 4. 编码器：默认 **增量式 10000PPR** ，绝对值编码器文末补充适配参数。

## 一、核心参数总表（面板直接设置，优先级从高到低）

### 1. 通讯模式组（H00 组，必设，切换 EtherCAT 总线）

表格

| 参数地址 | 参数名称     | 设定值     | 功能说明                                     |
| -------- | ------------ | ---------- | -------------------------------------------- |
| H00-02   | 通讯协议选择 | 2          | 0:RS485  2:EtherCAT（**必须设为 2** ） |
| H00-03   | 站点地址     | 0、1、2... | 多轴依次编号，单轴默认 0                     |

### 2. 控制指令来源 & 运行模式（H02 组，核心控制模式）

表格

| 参数地址 | 参数名称     | 设定值 | 功能说明                                                             |
| -------- | ------------ | ------ | -------------------------------------------------------------------- |
| H02-00   | 运行指令来源 | 1      | 0: 面板  1:EtherCAT 总线指令（指令由主站下发）                       |
| H02-01   | 控制模式选择 | 8      | **8:CSP 循环同步位置模式** （CiA402 标准，本工程唯一适配模式） |
| H02-02   | 原点模式     | 0      | 0: 无效（总线位置控制无需回零）                                      |

### 3. 脉冲 / 电子齿轮组（H05 组，单位换算核心，决定定位精度）

> 配套代码换算规则：`1圈(2π rad) = 10000 指令脉冲`
>
> | 参数地址 | 参数名称 | 设定值 | 功能说明 |
>
> |---------|----------|--------|----------|
>
> | H05-02  | 电机一圈指令脉冲数 | 10000 | 代码与伺服单位对齐基准，**严禁修改** |
>
> | H05-07  | 电子齿轮比分子 | 10000 | 增量编码器默认 10000PPR |
>
> | H05-09  | 电子齿轮比分母 | 1 | 齿轮比 = 分子 / 分母 = 1:1 |
>
> | H05-10  | 指令脉冲方向 | 0 | 0: 正向 1: 反向（电机转向反了再改） |

### 4. EtherCAT 总线周期 & DC 分布式时钟（H0A 组，同步关键）

表格

| 参数地址 | 参数名称          | 设定值 | 功能说明                                                   |
| -------- | ----------------- | ------ | ---------------------------------------------------------- |
| H0A-00   | EtherCAT 通讯周期 | 1000   | 单位 μs，固定 1000（和代码 1ms 周期严格对齐）             |
| H0A-01   | DC 同步模式       | 1      | 1: 启用分布式时钟（CSP 模式**必须开启** ，多轴同步） |
| H0A-02   | DC 同步偏移       | 0      | 默认 0，无需调整                                           |

### 5. 限位 & 急停（H06 组，安全配置，避免报错）

表格

| 参数地址 | 参数名称     | 设定值 | 功能说明                            |
| -------- | ------------ | ------ | ----------------------------------- |
| H06-00   | 正向硬件限位 | 0      | 0: 无效（现场无外接限位时关闭）     |
| H06-01   | 反向硬件限位 | 0      | 0: 无效                             |
| H06-04   | 急停功能选择 | 0      | 0: 急停无效（总线控制无需外部急停） |

### 6. 加减速 & 运动平滑（H07 组，配合轨迹算法抑振）

配合代码内 **S 型曲线 / 五次多项式** 轨迹，降低机械冲击：

表格

| 参数地址 | 参数名称     | 设定值 | 功能说明                         |
| -------- | ------------ | ------ | -------------------------------- |
| H07-00   | 加速时间     | 50     | 单位 ms，适配轨迹平滑输出        |
| H07-01   | 减速时间     | 50     | 单位 ms                          |
| H07-02   | S 曲线加减速 | 1      | 1: 开启伺服内部 S 曲线，双重抑振 |

### 7. 故障保护阈值（H09 组，解决位置偏差报错）

运行中常见 `Er.b0.00 位置偏差过大`，修改以下参数放宽阈值：

表格

| -------- | ---------------- | ------ | -------------------------- |
| H09-00   | 位置偏差过大阈值 | 2000   | 单位脉冲，放大阈值避免误报 |
| H09-01   | 位置偏差警告阈值 | 1500   | 警告阈值                   |

## 二、绝对值编码器伺服 额外参数（8388608 PPR）

如果使用 **汇川绝对值编码器电机** （非增量 10000PPR），仅修改**电子齿轮**部分，其余参数不变：

表格

| 参数地址 | 参数名称           | 设定值                      |
| -------- | ------------------ | --------------------------- |
| H05-02   | 电机一圈指令脉冲数 | 10000（保持不变，对齐代码） |
| H05-07   | 电子齿轮比分子     | 8388608                     |
| H05-09   | 电子齿轮比分母     | 10000                       |

换算逻辑：

编码器一圈 8388608 脉冲 → 折算为代码标准 10000 指令脉冲 / 圈，保证角度 - 脉冲换算一致。

## 三、终端电阻拨码（硬件必做，EtherCAT 通讯必备）

汇川 SV630N/SV660N/IS620N 伺服机身 **侧方拨码开关** ：

1. **单轴系统** ：唯一一台伺服 → 拨码 `ON`（开启终端电阻）；
2. **多轴串联系统** ：

* 总线 **第一个、中间所有伺服** ：拨码 `OFF`；
* 总线 **最后一台伺服** ：拨码 `ON`；

1. 作用：消除 EtherCAT 总线信号反射，避免断连、丢包、状态机切换失败。

## 四、InoTouch 上位机 批量配置方案（多轴高效调试）

多台伺服逐个面板设置效率低，使用**汇川 InoTouch**软件一键批量下发参数：

1. 电脑通过 USB 连接任意一台伺服，打开 InoTouch；
2. 菜单栏 →  **参数管理 → 参数导入 / 导出** ；
3. 先将上面全套参数在单轴设置完成， **导出参数文件 (.par)** ；
4. 依次连接其余伺服， **导入参数文件** ，一键复用所有配置；
5. 仅单独修改每台伺服 `H00-03 站点地址`（0/1/2...）即可。

## 五、上电顺序 & 标准操作流程（现场调试步骤）

1. **硬件接线**

   动力线、编码器线、EtherCAT 网线手拉手串联，最后一台打开终端电阻；
2. **伺服上电**

   依次给所有伺服上电，等待面板正常显示；
3. **参数核对**

   抽查 `H00-02=2`、`H02-01=8`、`H0A-00=1000` 三个核心参数；
4. **Linux 端准备**

   确认网卡名（`ip a` 查看），关闭网卡节能：
   bash

   运行

   ```
   sudo ethtool -C eth0 rx-usecs 1000
   ```
5. **运行程序**
   bash

   运行

   ```
   cd build
   sudo ./robot_ctrl
   ```
6. **正常现象**

   程序日志输出 `伺服使能成功，状态字：0x27`，伺服面板 `RUN` 灯常亮，电机进入励磁状态。

## 六、常见报错 & 对应参数修复（现场高频问题）

### 1. 报错 Er.b0.00 位置偏差过大

* 原因：轨迹指令与电机实际位置偏差超限
* 修复：增大 `H09-00`（位置偏差阈值），同时检查电子齿轮比 `H05-07/H05-09`。

### 2. EtherCAT 无法进入 OP 运行状态

* 原因 1：`H00-02` 不是 2（通讯协议未切 EtherCAT）→ 改 H00-02=2；
* 原因 2：终端电阻未开启 → 最后一台伺服拨码 ON；
* 原因 3：DC 时钟未开启 → 改 H0A-01=1。

### 3. 电机方向反转

* 修复：修改 `H05-10 指令脉冲方向` = 1。

### 4. 电机抖动、异响

* 修复：开启伺服 S 曲线 `H07-02=1`，适当加大加减速时间 `H07-00/H07-01`。

### 5. 伺服使能立即报错 Er.01.00 过流

* 原因：电机动力线相序错误 / 机械卡死；
* 排查：断电检查 UVW 动力线、机械负载。

## 七、参数恢复出厂（配置错乱时重置）

如果参数调乱无法恢复，先恢复出厂再重新配置：

1. 参数地址 `H00-01` = 1 → 恢复出厂参数；
2. 伺服断电重启；
3. 从头按照本文清单重新设置全部参数。
